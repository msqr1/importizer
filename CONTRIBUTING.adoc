= Contributing
:hide-uri-scheme:

Thank you for contributing to importizer!
This page gets you from zero to a working build and hopefully a passing test run.
Everything else lives in link:/docs/[`docs/`].

== Quick start
=== 1. One-time setup
* *Linux:* Use Alpine Linux container, see xref:/docs/Building.adoc#linux-pre-setup[Linux pre-setup].
* *Windows:* Enable
https://learn.microsoft.com/en-us/windows/advanced-settings/developer-mode[Developer Mode] so
symbolic links work without Administrator privileges.
* *Git:* Run after cloning:
[,bash]
----
# Keep permission of files in scripts/ executable on commit
git config core.hooksPath .githooks

# Let pulls overwrite the moving continuous tag
git config --add remote.origin.fetch "+refs/tags/continuous:refs/tags/continuous"
----

=== 2. Environment setup
Run the setup script for your OS in *every new terminal*, before anything else.
It checks your tools and sets the environment variables the build relies on.
[,bash]
----
# Linux
distrobox enter importizer-alpine
. scripts/setup/Linux.bash

# MacOS
. scripts/setup/Macos.bash

# Windows (PowerShell)
. scripts/setup/Windows.ps1
----
Note the leading `.`: scripts must be sourced, not executed.

=== 3. Build and test
[,bash]
----
# --preset importizer MUST ALWAYS be specified
cmake -B build -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=TRUE --preset importizer
cmake --build build --config Debug
ctest --test-dir build/tests -C Debug -j
----
The binary ends up in `build/importizer`.
